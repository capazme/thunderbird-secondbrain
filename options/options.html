Setup Ollama (una tantum)

Ollama per default rifiuta le richieste delle estensioni. Esegui nel Terminale e riavvia Ollama:

launchctl setenv OLLAMA_ORIGINS "moz-extension://*"

Questo comando si azzera al riavvio del Mac. Per renderlo permanente, esegui una volta lo script scripts/persist-ollama-origins-macos.sh incluso nel progetto (vedi README).
